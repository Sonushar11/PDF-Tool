API

These endpoints return JSON for the signed-in session, so an MCP server or script can call them against a loaded document:

GET /extract/markdown.json
Markdown plus page metadata
GET /extract/text.json
Raw text layer, no Markdown inference
GET /extract/download.md
Markdown as a file download

All three accept ?pages=1-3,7, ?tables=0 and ?breaks=0.
